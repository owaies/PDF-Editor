# Contributing to PDF-Editor

Keep contributions focused, testable, and consistent with the existing architecture.

## Workflow
1. Create a focused branch.
2. Reproduce the issue or define expected behavior.
3. Make one coherent change.
4. Run available lint, build, test, or validation checks.
5. Commit related changes separately with clear messages.

## Safety
- Never commit secrets or local environment files.
- Protect user data and authentication boundaries.
- Avoid unrelated rewrites.
- Update docs when behavior or setup changes.

## Pull requests
Explain what changed, why, how it was verified, and any known limitations.
